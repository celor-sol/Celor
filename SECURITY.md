# Security Policy

## Supported Versions

Currently, the Celor infrastructure is in heavy development. 
The following versions are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in the Celor core, provider adapters, or telemetry pipelines, please **DO NOT** open a public issue.

Instead, please email the security team at **security@celorinfra.com** with a description of the vulnerability and steps to reproduce it.

We take all reports seriously and will strive to acknowledge your report within 48 hours and provide a timeline for a fix.
